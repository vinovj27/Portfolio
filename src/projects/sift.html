Overview

Sift is a full-text search engine built from first principles: a positional inverted index, Okapi BM25 ranking, phrase and boolean queries, typo correction, autocomplete and a web UI that searches as you type.

Out of the box it indexes the Python standard library's own documentation, about 4,000 modules, classes and functions. It reads the source with ast rather than importing it, so no library code runs. Point it at any folder to search your own notes or code instead.

Title tokens sit at positions 0 to n and body tokens start at 1,000, so a phrase can never match across the title and body boundary, and title hits can be weighted separately.

SnippetsThe best window of text with matches highlighted and HTML-escaped

The ranking in code

For each candidate document, every query term contributes its rarity (IDF) times a saturating term-frequency score, normalised by document length:

norm = K1 * (1 - B + B * idx.lengths[doc_id] / avg)
for term in set(query.terms):
    tf = idx.weighted_tf(term, doc_id)
    if tf:
        score += idx.idf(term) * tf * (K1 + 1) / (tf + norm)

What the tests prove

  • Term frequency and title boosts put the most relevant document first
  • Rare terms outweigh common ones
  • Phrases require adjacent words, in order
  • Required and excluded terms filter correctly
  • Snippets highlight matches and escape HTML
  • "Did you mean" fires only for unknown words
  • Saved indexes load back with identical rankings
  • On the real standard library, "serialize object to json" finds json.dump

Run it

Python 3.10 or newer, no installs needed.

python -m sift serve                         # web UI at http://localhost:8000
python -m sift search '"thread pool"'        # search from the terminal
python -m sift serve --folder ~/notes        # search your own files
python -m unittest discover -s tests

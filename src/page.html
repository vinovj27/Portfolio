Distributed systems

Conveyor

A distributed task queue that keeps going when workers crash.

A broker stores jobs in SQLite and leases them to worker processes over HTTP, in the spirit of Celery and Sidekiq. If a worker dies mid-job, its lease expires and another worker picks the job up. Failing jobs retry with exponential backoff and jitter, and jobs that keep failing land in a dead-letter queue for inspection.

  • Atomic job claims with UPDATE … RETURNING inside an immediate transaction
  • Heartbeat lease renewal, plus fencing so a stale worker can't overwrite a result
  • Priorities, delayed jobs, named queues and a live dashboard with one-click retry

Search & information retrieval

Sift

A search engine that answers in milliseconds and forgives typos.

Sift builds a positional inverted index and ranks results with Okapi BM25. Out of the box it indexes the Python standard library's own documentation, about 4,000 modules, classes and functions, read with ast so no library code runs. It can also index any folder of notes or code. A web UI searches as you type.

  • Exact phrases using token positions, plus +required and -excluded terms
  • Code-aware tokens: ThreadPoolExecutor becomes thread, pool, executor
  • "Did you mean" via bounded edit distance, autocomplete and highlighted snippets

Databases

KVLite

A key-value database that survives a pulled plug.

Every write is appended to a checksummed write-ahead log before it's applied, the approach behind Redis's append-only file and Postgres crash recovery. On restart, KVLite replays the log; if a power cut left a half-written record, its checksum fails and the log is truncated to the last good entry. A TCP server speaks a Redis-style protocol to many clients at once.

  • CRC32 per record, with base64-encoded keys and values so any text is safe
  • Snapshot compaction with fsync and atomic rename, so the snapshot is never half-written
  • TTL expiry, atomic INCR, and fsync or buffered durability modes

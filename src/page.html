Signer Data Migration & Reconciliation

Before a bank cuts over to a new platform, every authorised signer must exist, with the right details, in every system that depends on them. Real-world name problems, and how the pipeline handles each

MÜLLER ≠ MUELLER

German convention spells Ü as UE. Unicode normalisation alone gives MULLER, so I added a multi-letter expansion table.

ŁUKASZ ≠ LUKASZ

Polish Ł is its own letter, not L plus an accent, so standard stripping can't decompose it. It needed an explicit mapping.

JOSÉ GARCÍA-LÓPEZ

Generic stripping via Unicode decomposition covers French, Spanish, Polish, Croatian and other Latin scripts without per-language lists.

KOWALSKA NOWAK → KOWALSKA

One system truncated compound surnames, so first-word matching runs as a fallback.

KUMAR KUMAR

The same name entered in both name fields. Duplicate-word removal cleans it before comparison.

DÉBORAH + compound surname

Needed accent stripping and truncation together. I generated first-word variants after normalisation so the stages compose.

The hardest bug: unrelated names matching

Symptom

After adding the letter-frequency "possible match" stage, completely unrelated names were being flagged as matches.

  1. Ruled out duplicate function definitions, stale cached files and wrong file paths
  2. Hand-calculated expected scores to prove the logic should reject these pairs
  3. Wrote an isolated, zero-dependency test script to separate "the math is wrong" from "something else interferes"
Root cause & fix

A variable-naming collision merged first and last names into one bag of letters, so a mismatch in one part could be cancelled out by a coincidental overlap in the other.

I compared first names to first names and last names to last names independently, and added a length pre-filter that rejects unrelated candidates before scoring.

Scaling to the full dataset

  • Mid-project the source export grew from 37,508 to 85,315 records with a completely different column schema. A normalisation layer translated it, so no downstream function had to change.
  • Fuzzy matching scanned the whole target index for every unmatched record, which became too slow. Bucketing candidates by first letter cut the search space while keeping accuracy.
  • A loose similarity threshold was producing false positives reported at 100%. I raised the threshold and made the function report its true similarity score.

What I delivered

  • A multi-sheet Excel report with match status, matching stage and confidence for every signer
  • Side-by-side source and target names and IDs, so reviewers verify a match without re-running code
  • An accented-character audit across every source system, sizing the encoding problem for the team
  • A standalone transliteration tool that converts accented names to plain-English spellings across four systems

Distributed systems

Conveyor

A distributed task queue that keeps going when workers crash.

A broker stores jobs in SQLite and leases them to worker processes over HTTP, in the spirit of Celery and Sidekiq. If a worker dies mid-job, its lease expires and another worker picks the job up. Failing jobs retry with exponential backoff and jitter, and jobs that keep failing land in a dead-letter queue for inspection.

  • Atomic job claims with UPDATE … RETURNING inside an immediate transaction
  • Heartbeat lease renewal, plus fencing so a stale worker can't overwrite a result
  • Priorities, delayed jobs, named queues and a live dashboard with one-click retry

Databases

KVLite

A key-value database that survives a pulled plug.

Every write is appended to a checksummed write-ahead log before it's applied, the approach behind Redis's append-only file and Postgres crash recovery. On restart, KVLite replays the log; if a power cut left a half-written record, its checksum fails and the log is truncated to the last good entry. An asyncio TCP server speaks a Redis-style protocol to many clients at once.

  • CRC32 per record, with base64-encoded keys and values so any text is safe
  • Snapshot compaction with fsync and atomic rename, so the snapshot is never half-written
  • TTL expiry, atomic INCR, and fsync or buffered durability modes

Databases · Java 17

              
KVLite

              
A persistent key-value database with a Redis-style TCP server. Every write hits a checksummed write-ahead log first, so the data survives a crash, a torn write or a pulled plug.

              
    
                
  • Crash recovery that detects and truncates corrupted log tails
    • 
                
  • Snapshot compaction with fsync and atomic rename
    • 
                
  • TTL expiry, concurrent clients and a throughput benchmark
    •
